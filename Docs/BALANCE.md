# 双档位数值表

两套参数共用一张 CSV。选入口或重开时读取对应一列，本局参数在开局时固定。

| 列 | 含义 |
|---|---|
| Key | 程序识别的参数名 |
| PC | 当前版本，默认沿用 v0.6 |
| Classic | 以《空袭》4.69 Easy 为基线的原版数值 |
| 说明 | 参数含义和单位 |

在项目中编辑 `Assets/StreamingAssets/Balance.csv`。在 Windows 试玩包中编辑 `Skybreach_Data/StreamingAssets/Balance.csv`。用 Excel 时请保存为 CSV UTF-8（逗号分隔），小数使用点。保留前三列的列名、顺序和参数名。数字越界、重复键或缺少参数时，所选入口会显示要修正的条目。修好后可直接再点一次入口。

例如，将 `PlayerHealth` 的 **PC** 列从 100 改成 120，重开 PC 档后每条命为 120 HP，Classic 档仍为 1 HP。要指定开局阵容，可编辑 `Opening1` 到 `Opening6`，使用 B 普通机、A 装甲机、F 高速机、H 直升机，例如 `B|F|H`，填 `-` 时改用波次预算随机生成。

## Classic 参数来源

| 规则 | 当前实现 |
|---|---|
| 波次、补给和基础投弹 | 使用 1.12 次幂预算、每四波随机补给、25 Hz 倒计时和 160 基础计数。换波等待约 1.6 秒，补给机计入换波 |
| 生命与升级 | 3 条命，常规爆炸命中掉命，4 秒复活保护。复活从已有升级里随机失去一项。穿甲同时最多两枚火箭，普通火箭位可继续增长 |
| 敌机强化 | 速度强化倍率 1.6。射速每级约减半。装甲挡一次命中，默认约 5.8 秒恢复。机群只从当前已实现机型中组合，强化分配概率为近似 |
| 地形与动作换算 | 以 480 像素屏高、39 像素人物贴图和 Unity 1.65 单位胶囊为参照，普通炸弹、火箭和手挖半径约为 1.06、0.42、0.21 单位。用 0.25 单位网格和更浅土层。移动速度、跳跃、直升机攻击时序用现有 Unity 运动与攻击模型近似 |
| 成绩 | 局内和结算以完成波次为主，最高波次单独记录 |

原版高空特殊袭击、集束和燃烧等额外机型仍需独立实现。Classic 使用同一套 Windows 画面、碰撞和操作，货物与残骸保留 Unity 的对象上限和过期规则。分支数值以项目内表为准。

中文界面从 Windows 已安装的中文字体中取字，优先使用微软雅黑。
