# v0.4.1 地形消耗调整

玩家反馈：炸弹破坏范围过大，少量波次后土层就接近耗尽，后续挖掘和调整掩体的空间不足。

原因是普通炸弹使用半径 2.1 的圆形开挖，而初始土层只有约 8 单位深。命中坑底时仍以同样半径移除土壤，集中轰炸很快触及最底层基岩。

## 调整后的规则

| 开挖来源 | v0.4.0 | v0.4.1 |
|---|---|---|
| 普通炸弹、敌方火箭 | 圆形半径 2.1 | 椭圆：横向半径 1.05、纵向半径 0.65 |
| 玩家火箭 | 圆形半径 1.5 | 椭圆：横向半径 0.85、纵向半径 0.75 |
| 右键主动挖掘 | 圆形半径 0.72，有距离和时间间隔限制 | 保留原规则 |

地形单元仍为 0.5 单位。实际坑深与落点、土层边缘和网格取整有关，表中半径不等于每次命中必定降低的表面高度。

爆炸伤害与开挖尺寸分别计算；本次调整没有降低爆炸的伤害范围。土层先吸收当前爆炸，再开挖弹坑。较小的坑会保留更多掩体，但反复轰炸仍会削薄土层、扩大暴露程度。

地形不自动恢复。除原有最底层基岩外，没有增加不可破坏层、弹坑深度上限或同地点免疫。

## 受控验收

使用真实 `DestructibleGround` 网格和开挖实现，在隔离的地形实例上比较旧圆形规则和新椭圆规则。两边使用相同初始地形和落点序列，落点高度各自跟随当前表面，模拟炸弹继续打到坑底。命中位置位于表面上方 0.16 单位。

| 指标 | 旧规则 | 新规则 |
|---|---:|---:|
| 指定地表位置单次命中移除土格 | 24 | 4 |
| 该位置单次命中降低表面高度 | 2.0 | 0.5 |
| 同一位置连续六次命中的坑深 | 8.0 | 3.0 |
| 108 次分散命中后剩余土量 | 26.7% | 79.9% |

分散命中分为六组，每组十八次；按固定顺序覆盖二十四条落点线。剩余土量是整个地图的实心网格数量占比，包含边缘和基岩，不能解读成每个位置的剩余土深。

| 累计命中数 | 旧规则剩余土量 | 新规则剩余土量 |
|---|---:|---:|
| 18 | 83.5% | 96.8% |
| 36 | 68.2% | 93.4% |
| 54 | 54.0% | 90.0% |
| 72 | 41.3% | 86.6% |
| 90 | 28.3% | 83.3% |
| 108 | 26.7% | 79.9% |

这些是固定命中夹具，**不是人工游玩六波，也不是对实际生存时间的保证**。实际损耗还取决于命中分布、玩家移动、主动挖掘、弹体被角色挡住等因素。

另外验证了真实炸弹的下落 → 碰撞 → 爆炸 → 开挖路径，以及轰炸后的主动挖掘、继续加深、较小弹坑削弱掩体后提高后续伤害等行为。证据保存在 [独立程序记录](Validation/standalone.json)；检查实现为 `Assets/Scripts/TerrainBalanceChecks.cs`。

## 后续试玩关注点

观察五至十波内是否仍有足够的掩体调整空间、主动挖掘是否仍有价值，以及长期站在同一坑内是否过于安全。优先根据这些反馈继续调整半径和土层深度；特殊重型弹药以后可拥有独立的开挖参数。
