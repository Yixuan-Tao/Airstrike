# v0.7.0 Windows 验收

在 Windows x64、Unity 6000.3.27f2、URP 17.3.0 下验收。构建与压缩包信息见 [acceptance.json](acceptance.json)，独立程序记录见 [standalone.json](standalone.json)。

- 双入口验收覆盖按档读表、非法数据定位、中文菜单及战斗 HUD、英文切回、返回菜单、Classic 致命命中、护盾、穿甲上限、复活掉升级和同档位重开。[入口验收](menu.json)
- 离屏相机核对简体中文、英文菜单和 Classic 战斗 HUD。[主菜单](../Images/mode-menu.png)
- 调度检查覆盖前六波实走调度、前四十波预算、每四波补给、约1.6秒换波、普通炸弹跨波。
- 普通机夹具检查离开战区时倒计时冻结、进入后恢复、随机投弹时间和远离玩家投弹。
- 用真实火箭击落敌机，观察下坠、即时计分和落地。检查残骸参与碰撞、遮挡爆炸、可站立和可挖除，检查玩家周围、复活区和全局上限。
- 保留浅弹坑、跨阶、补给、飞行员救援、穿透、暂停和重开的回归验收。
- 独立的单架普通机观测运行三组各约120模拟秒，记录爆炸落点、局部土量和连续步行区段。[观测数据](pacing.json)

验收使用内部控制输入，在无图形、无声音的独立程序中运行。为了重复验证，残骸夹具强制坠落，六波调度夹具加速生成并脚本清理敌机。单机观测使用固定种子和保护角色。人工走位、实战难度和图形性能仍需实际试玩。
