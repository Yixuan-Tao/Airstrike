# v0.3.0 运行验收

2026-11-01 在 Windows / Unity 6000.3.27f2 / URP 17.3.0 上完成本地 Windows x64 / Mono 独立程序验收。

- 构建成功，零错误、零警告；进程退出码为 0，59 条自动检查通过，运行异常为 0。
- 保留移动、二段跳、掩体吸收、贴墙射击、80 次连续爆炸及三次重开的回归检查。
- 高速机完成三枚连投；直升机先预警、锁定原位置，再发射非追踪火箭。
- 走近拾取火箭位和穿透补给；同时三枚火箭达到上限，重复满级补给转换成分数。
- 一枚穿透弹击落两个分开的目标；装甲目标受到一次 110 伤害后剩余 70 生命，没有被末端爆炸重复伤害；土墙仍能阻挡穿透弹。
- 升级在备用生命复活后保留，重新开始时清空。
- 实际波次调度推进到第七波，核对高速机、直升机、装甲机的引入顺序，以及第二、四、六波各产生一次补给奖励。
- Windows 压缩包的程序、运行库、游戏程序集和游玩说明已检查存在。

原始结果为 `standalone.json`；构建、程序集和压缩包哈希为 `acceptance.json`。本机完整日志位于 `Logs/`，不提交到仓库。

验收通过游戏内部控制输入运行，不发送系统键鼠事件。射击阶段固定目标位置，正常飞行、投弹、预警和火箭轨迹另行检查。时序和碰撞使用受控物理夹具；六波调度验收加快了生成与间隔，并通过伤害调用清理敌机。这不代表人工完成了六波实战。

独立程序使用无图形、无声音模式，人工手感、声音、长期稳定性和实际图形性能仍需试玩。记录来自开发电脑，不是 GitHub Actions 运行记录。

预览图安排了三类敌人、补给和坑洞，并通过实际拾取设置升级状态，不作为性能证据。
