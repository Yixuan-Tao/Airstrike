# v0.5.0 运行与画面验收

2026-11-01 在 Windows / Unity 6000.3.27f2 / URP 17.3.0 上完成独立程序验收及编辑器离屏画面复核。

- Windows x64 / Mono 构建成功，零错误、零警告；进程退出码为 0，109 条自动检查通过，运行异常为 0。
- 新玩法检查覆盖火箭击落补给机并只掉一箱、货物保持、拾取跳跳靴、三次空中跳跃和高度边界、升级复活保留、EMP视野范围及弹体保留、飞行员缓降/着陆/加命、隔墙领取、生命上限、暂停与过期。
- 实际波次调度在补给机、箱子、飞行员仍存在时进入下一波。第2、4、6波各派一架补给机；只有被击落的补给机产生货物，清波不自动发箱。
- 增加八条地形消耗检查：单发炸弹、玩家火箭、108 次分散命中、同点连续轰炸、主动挖掘及真实炸弹落地开挖；具体参数与固定夹具结果见 [地形平衡说明](../TERRAIN_BALANCE.md)。
- 保留移动、掩体、敌机、补给、穿透边界、六波调度、80 次爆炸及三次重开的回归检查。
- 分节人物模型保留原胶囊高度 1.65、半径 0.32；实际移动期间动作状态持续更新。
- 同时触发 40 组爆炸表现时，特效池保持 16 组上限；等待生命周期结束后活动特效归零。
- 核对渐变天空、分层远山、人物、裸土坑底、补给机、新补给符号、飞行员和界面的1600×900离屏预览。
- 检查压缩包包含独立程序、运行库、游戏程序集和游玩说明。

固定位置的单发炸弹移除 4 格土、坑深 0.5 单位；旧规则为 24 格、2 单位。同点连续六次命中后坑深为 3 单位，旧规则为 8 单位。108 次分散命中后新规则剩余土量约 79.9%，旧规则约 26.7%；这是固定落点夹具，不是人工六波实战预测。实际下落炸弹另测得移除 5 格土，说明碰撞落点会影响离散网格结果。

原始独立程序结果见 `standalone.json`，构建及程序集、压缩包哈希见 `acceptance.json`。画面对比见 `../ART_DIRECTION.md`。

输入通过游戏内部通道注入，不操作其他窗口。射击和碰撞使用受控夹具，正常 AI 行为另行检查；六波验收加速了生成与间隔并调用伤害清理目标，不代表人工完成六波实战。

补给机击落使用真实玩家火箭，EMP和救援分别使用受控目标与概率夹具。常规回归关闭随机飞行员掉落，专门夹具中强制掉落以重复验证；真实默认概率为25%。过期检查临时加速游戏时间，验证资源生命周期，不能代表长时间运行测试。补给与生命规则见 [说明](../SUPPLY_AND_RESCUE.md)。

独立验收以无图形、无声音模式运行。离屏预览属于编辑器画面核对，不是独立程序图形性能验证。人工手感、声音、长期稳定性和实际帧率仍需试玩；这些记录不是 GitHub Actions 运行记录。
